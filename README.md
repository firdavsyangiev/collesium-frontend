# Collesium Frontend

React va TypeScript asosidagi Collesium Athletics mijoz ilovasi.

## Ishga tushirish

1. `.env.example` faylidan `.env` yarating.
2. `npm install` buyrug'ini bajaring.
3. Backend `3017` portda ishlayotganini tekshiring.
4. `npm start` buyrug'i bilan frontendni ishga tushiring.
